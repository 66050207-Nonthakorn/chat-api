## ภาพรวม

ระบบแชทขนาดเล็กสำหรับวิชา Cloud Computing ใช้แสดงการประมวลผลที่ทดแทนอินสแตนซ์ได้ การเก็บไฟล์แบบ object ฐานข้อมูลภายนอก เครือข่าย private การส่งเหตุการณ์ข้าม replica ด้วย Pub/Sub การกู้คืน CI/CD การติดตามระบบ และการล้างทรัพยากรที่ทำซ้ำได้

**ฉบับภาษาไทยที่รวมข้อสรุปแล้ว:** 2026-10-25

**สถานะปัจจุบัน:** สรุปแบบและแผนสำหรับเดโมขั้นต่ำแล้ว ยังไม่ได้ยืนยันการพัฒนาแอป การทดสอบ บัญชี/เครดิต AWS การ deploy หรือผลวัดประสิทธิภาพ จะสมัคร AWS ภายหลัง และเริ่ม local ได้ก่อน

## ขอบเขตสาธิตขั้นต่ำ

เข้าสู่ระบบ ใช้ผู้ใช้และห้องที่เตรียมไว้ ส่งข้อความที่ยังแก้ไข/ลบไม่ได้ ดูประวัติ และกู้ข้อมูลหลังเชื่อมต่อใหม่ สาธิตส่งสดระหว่าง API คนละ task กู้ worker ที่อ่าน outbox ปล่อยเวอร์ชันแบบ rolling และดู dashboard เก็บผลทดสอบ scaling และ failover ตามเวลาหรือเครดิตที่ตรวจจริง

สถานะกำลังพิมพ์ ออนไลน์ ใบตอบรับการอ่าน หน้าจัดการกลุ่ม และแก้ไข/ลบข้อความอยู่ระยะถัดไป โดยเก็บนโยบายที่เลือกแล้วไว้ในหน้าข้อสรุป

## สถาปัตยกรรมที่เลือก

- **ส่วนหน้า:** Svelte + TypeScript + Vite เก็บไฟล์ใน private S3 ผ่าน CloudFront และส่งเส้นทาง API/auth/WebSocket ไป ALB ภายใต้ origin เดียว
- **ส่วนประมวลผล:** Go แบบ modular monolith ใช้ HTTP สำหรับคำสั่งถาวรและ WebSocket สำหรับเหตุการณ์สด API หลาย task และ Go worker แยก ทำงานบน ECS/Fargate ใน private subnet
- **ข้อมูล:** RDS PostgreSQL เก็บข้อความ สมาชิก session และ transactional outbox ตอบรับหลัง commit จัดลำดับต่อห้อง ป้องกันคำขอซ้ำและกู้ข้อมูลจากฐานข้อมูล
- **การส่งสด:** ElastiCache แบบ node ใช้ Valkey/Redis Pub/Sub ช่องร่วมแยกต่อ environment การแจ้งเตือนอาจสูญหายได้ แต่เรียกข้อความคืนจาก PostgreSQL
- **ความปลอดภัย:** คง Cognito ใช้ session ฝั่ง backend ใน PostgreSQL ตรวจสิทธิ์จากข้อมูลจริง จำกัด IAM เครือข่ายข้อมูลเป็น private และเก็บข้อมูลรับรองใน Secrets Manager
- **การส่งมอบและติดตาม:** Terraform, GitHub Actions/OIDC, deploy dev อัตโนมัติเมื่อมี environment, เลื่อน artifact ที่ทดสอบแล้วไปสาธิตด้วยมือ, rolling deployment และ CloudWatch/OpenTelemetry
- **รูปแบบใช้งาน:** พัฒนาบน local เปิด AWS ชั่วคราว พัฒนาใช้ Single-AZ RDS สาธิตความทนทานใช้ Multi-AZ เริ่ม task คงที่แล้ววัดก่อนเปิด autoscaling ที่มีเพดาน

## เครดิตและขั้นตอนถัดไป

เลือก **AWS Free account plan** โดยคงสถาปัตยกรรมเดิมและตั้งเป้าจ่ายเองใกล้ศูนย์ ยังไม่ยืนยันสิทธิ์บัญชี ยอดเครดิต วันหมดอายุ หรือบริการที่ใช้ได้ งานเอกสารนี้ไม่อนุมัติการอัปเกรดเสียเงิน ซื้อโดเมน หรือสร้างทรัพยากร

Singapore เป็นสมมติฐานราคาที่ยังไม่ได้เลือกจริง ประมาณการเดิมคือใช้บริการตามมิเตอร์ราว USD 20–30 สำหรับรอบที่จำกัดเวลา ซึ่งอาจใช้เครดิตชำระได้เมื่อยืนยันสิทธิ์แล้ว ไม่ใช่คำรับรองว่าฟรีหรือเป็นงบเงินสดส่วนตัวที่ยอมรับ

**งานแรกเมื่อเริ่มพัฒนา:** M1 แกนข้อความที่บันทึกถาวรบน local แล้ว M2 การส่งข้าม replica ด้วย Pub/Sub และการกู้คืน ก่อนขึ้นคลาวด์ให้ตรวจรายการเตรียมพร้อม ตารางหกสัปดาห์เป็นข้อเสนอ ต้องกำหนดวันที่จริงตามตารางเรียนและเวลาของทีม
