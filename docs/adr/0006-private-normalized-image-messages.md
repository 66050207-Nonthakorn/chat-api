# รูปในข้อความเป็นเนื้อหาส่วนตัวที่ผ่านการปรับรูป

เพิ่มข้อความรูปภาพใน DM และกลุ่ม โดยผู้ใช้ยืนยันเมื่อ 2026-11-04 ให้รูปอยู่ภายใต้กฎสมาชิกปัจจุบันและประวัติทั้งหมดตาม ADR 0002 ไม่มี public URL ถาวร และเก็บรูปที่ส่งแล้วตลอดช่วงโครงการเช่นเดียวกับข้อความ การเก็บไฟล์และการส่งไฟล์จึงต้องรองรับการตรวจสิทธิ์เมื่อขอดูรูป ไม่สามารถเรียกคืนสำเนาที่ดาวน์โหลดไปแล้วได้

เลือกเก็บเฉพาะภาพสำหรับแชทที่ตรวจไฟล์จริง ปรับแนวภาพ ลบ metadata เช่น GPS และจำกัดด้านยาว 2,560 px โดยไม่ขยายภาพเล็กและคงความโปร่งใส แทนการเก็บต้นฉบับให้ดาวน์โหลด เพื่อให้การส่งรูปมีขอบเขตข้อมูลและขนาดที่ชัดเจน ข้อแลกเปลี่ยนคือสูญเสีย metadata และไม่สามารถกู้ไฟล์ต้นฉบับแบบ byte-for-byte จากระบบได้ ขนาด/คุณภาพและเกณฑ์ประมวลผลกำหนดใน spec ที่ยืนยันแล้ว

**สถานะการส่งมอบ:** ผู้ใช้ยืนยันแบบออกแบบฉบับสุดท้ายเมื่อ 2026-11-04 Backend พัฒนาและทดสอบ local integration แล้ว ยังไม่ได้ deploy AWS หรือส่งมอบ frontend ดู [คู่มือรูปภาพ](../image-messages.md), [spec](../../.scratch/image-messages/spec.md) และ [ADR 0007](0007-image-send-and-private-storage.md)
