# เดโมขั้นต่ำและการใช้ AWS แบบจำกัดเวลา

เน้นคะแนนวิชา Cloud Computing ด้วยแอปแชทขนาดเล็กที่สาธิต compute, storage, database, security, real-time, recovery และ deployment ได้จริง เลือก AWS Free account plan โดยคงสถาปัตยกรรมเดิม พัฒนา local ก่อนและเปิดคลาวด์เฉพาะรอบทดสอบ/ซ้อม/สาธิต

- **บันทึก:** 2026-10-28 จากข้อสรุปเดิม ไม่ใช่การอนุมัติสร้างทรัพยากร
- **ข้อแลกเปลี่ยน:** ลดฟีเจอร์ผลิตภัณฑ์เพื่อเหลือเวลาสำหรับหลักฐานโครงสร้างพื้นฐาน; บริการตามมิเตอร์ยังใช้เครดิตและต้อง cleanup

## ขอบเขตที่ยืนยัน

เจ้าของยืนยันเดโมขั้นต่ำตาม rubric: เข้าสู่ระบบ ผู้ใช้/ห้องที่เตรียมไว้ ข้อความและประวัติ การ reconnect ส่งสดข้าม replica กู้ worker ปล่อยเวอร์ชัน และ dashboard เน้นโครงสร้างพื้นฐานมากกว่าฟีเจอร์

การคุยประมาณราคาก่อนตั้งงบ (D42) และน้ำหนักเดโม (D43) ถูกสรุปด้วยขอบเขตข้างต้นและเป้าหมายจ่ายเองใกล้ศูนย์ ข้อเสนอให้สำรองเงินส่วนตัว USD 50 **ไม่ได้รับการยอมรับและไม่ใช่งบที่อนุมัติ**

เลือก **AWS Free account plan และคงสถาปัตยกรรมเดิม** สมัครภายหลัง เครดิต วันหมดอายุ บริการที่ใช้ได้ region และ quota ยังไม่ตรวจ การใช้เครดิตคือต้นทุนตามมิเตอร์ ไม่ใช่การใช้บริการฟรีถาวร

ยังไม่อนุมัติให้เปลี่ยนเป็น Lambda/DynamoDB เอา Cognito ออก อัปเกรดบัญชีแบบเสียเงิน ซื้อโดเมน หรือสร้างทรัพยากร

## เงื่อนไข

- M1/M2 ทำ local ได้; Cognito จริงและ cloud demo รอสมัคร/ยืนยันบัญชี
- ตาราง 6 สัปดาห์และ baseline/stretch เป็นแผน ไม่ใช่กำหนดส่งหรือผลวัด
- ราคา Singapore ที่ตรวจ 2026-10-25 เป็นสมมติฐาน ต้องตรวจใหม่ก่อนใช้
- USD 20–30 เป็นประมาณค่าบริการรอบสั้นก่อนหักเครดิต ไม่ใช่งบเงินสดที่ยอมรับหรือคำรับรองว่าฟรี
- Budget alert ไม่ใช่ hard cap; ตรวจ plan/expiry/service/quota/เวลาและ teardown
- Free plan ใช้บริการไม่ได้ให้ทบทวนกับเจ้าของ ไม่ upgrade/เปลี่ยนสถาปัตยกรรมอัตโนมัติ
