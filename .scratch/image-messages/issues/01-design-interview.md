# 01 — ออกแบบการส่งรูปภาพ

Type: grilling
Status: resolved

## เป้าหมาย

สัมภาษณ์ผู้ใช้ตามลำดับการตัดสินใจ ตรวจข้อเท็จจริงจากระบบ และจัดทำข้อกำหนดสำหรับการส่งรูปในข้อความ

## ขอบเขตงาน

- บันทึกข้อสรุปใน [spec](../spec.md) และ [map](../map.md) ระหว่างการสนทนา
- บันทึกคำศัพท์ที่ตกลงแล้วใน GLOSSARY.md และสร้าง ADR เมื่อมี trade-off ที่สมควรบันทึก
- ยืนยันความเข้าใจร่วมกันเมื่อคำถามครบ ก่อนเริ่ม implementation

## Answer

ยืนยันขอบเขตและแบบออกแบบครบถ้วน ดู [spec](../spec.md), [ADR 0006](../../../docs/adr/0006-private-normalized-image-messages.md) และ [ADR 0007](../../../docs/adr/0007-image-send-and-private-storage.md) แบบออกแบบใช้หนึ่งคำขอ Send ผ่าน API เดิม พร้อม private storage และ cleanup เฉพาะรูปที่ยังไม่ส่ง ไม่มี implementation หรือผลตรวจรับฟีเจอร์รูปในงานนี้

เอกสารฉบับสุดท้ายบันทึกใน [Notion](https://www.notion.so/40e766880300818bb5ecf5fa73f0154c) และเชื่อมจากหน้าสถาปัตยกรรม/ข้อสรุปการออกแบบเดิมแล้ว
